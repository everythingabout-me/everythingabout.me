01

字体

系统字体栈，逐字回退

苹果不是用一款字体覆盖中英文，而是让系统按字符挑字体：拉丁走 SF Pro，中文走 PingFang SC；日文 Hiragino，韩文 Apple SD Gothic Neo。 网页里用 -apple-system 就能拿到这条路径。我们跟着这个做法，选一个字体栈，而不是一款单体字体。 

/* 拉丁优先，中文字体放在后面；浏览器逐字回退 */
--font-ui:
  -apple-system, BlinkMacSystemFont,
  "SF Pro Text", "SF Pro Display", "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
  "Noto Sans SC", "Hiragino Kaku Gothic ProN", "Yu Gothic",
  "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans JP", "Noto Sans KR",
  "Helvetica Neue", Arial, sans-serif;

/* 只有代码、路径用等宽 */
--font-mono:
  ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, monospace;

字体栈的顺序就是回退顺序：不要把中文字体放在 -apple-system 前面，否则 Mac 上的拉丁也会先用中文字体。

为什么这样选

系统字体最贴合平台。中文在 macOS 上就是苹方，在 Windows 上就是雅黑；不需要加载几 MB 的 CJK webfont，也没有 FOUT。

不用单一 webfont 覆盖全部语言。Noto Sans SC 全量很大，首屏代价高，而且中文渲染不如系统字体贴合平台。

可选：如果希望 Windows / Android 的拉丁也接近 SF，可在 -apple-system 之后加自托管的 Inter；中文继续走系统。Mac 仍然是 SF。

03

按钮

一个主行动，一个危险确认

默认按钮是 36px 高、10px 圆角、13 / 600；小号 30 / 8 / 12，大号 44 / 10 / 14。主按钮只有蓝，危险按钮只有砖红；次级、幽灵、链接都不上色。

Primary · 主行动

每个视图最多一个。上传、继续、保存。蓝底白字；深色下亮蓝 + 深字。

Secondary · 次级

替代动作、输入旁的小操作。白底、1px 边框、墨色字；hover 只换底色。

Critical · 不可逆

只在确认弹窗里用实心；行内删除、移除密码用文字按钮。不要用珊瑚红。

Ghost · 图标 / 轻操作

图标按钮 30×30、8px 圆角；默认灰，悬停墨色。

Link · 文本跳转

页面切换、补充入口。Blue ink；hover 加下划线。不拿它做主要动作。

Sizes

30 / 36 / 44。表单提交用 44；输入框旁的发送验证码也跟输入同高。

规则
  • 主按钮不承担品牌装饰；它只表示“这一步继续”。一个视图一个。
  • 次级按钮永远中性；不要出现蓝色次级、红色次级。
  • 危险动作先问一句；确认按钮才用实心砖红，取消永远是次级。
  • 没有渐变、没有硬阴影、没有两色按钮；焦点用 2px 外描边。

图标

16px 网格，1.5px 线

一套自定义线性图标：16×16 网格、1.5px 描边、圆头圆角、currentColor、无填充。常用 16px，密集处 14px，空态 20px。

规则
  • 文件类型不按类型上色：所有 glyph 都是同一块浅蓝底 + 同一个深蓝线，只靠形状区分。
  • 默认 --text-2；可交互 / 悬停 --blue-ink；只有删除的悬停用 --danger。
  • 不混用其他图标库；不用 emoji；不用多色图标；图标按钮必须有 aria-label。
  • 默认 30×30；密集行内（文件行操作）用 26×26，图标 14px。

表单

一条底线，一个焦点
