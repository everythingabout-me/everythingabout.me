这一版砍掉了什么

只有一层：事件卡

没有年标题、没有月标题、没有「N 个文件 / N 个事件」。每张卡自带完整日期（含年份），从上往下就是时间。

代价是「哪个月安静」不再一眼可见；换来的是滚起来没有停顿，卡片是页面上唯一的内容单位。

卡片是类型化的

内置四种：photo（1–4 张图 + 一句话）、note（纯文字）、metric（一行数字）、html（应用自己的版式）。html 跑在沙箱 iframe 里，我们只注入设计 token——稿里那张剧票就是。

事件从哪来

站内自己写（native）、文件流水线自动聚（auto）、三方应用用 token 写（app）。来源只出现在日期那一行（「晨跑」来自 Strava、「剧票」来自大麦）。

没有编辑；也没有详情按钮——有 detail_url 时标题才是链接，没有就不可点。结构和 API 见 docs/design/events.md。

健康：变了才说话

只有「8 月睡得少」这种真的变了的月份才出现一张卡。没有每月图表，也没有年度总览面板——年度总览会把「年」这个层级重新带回来，先撤掉。

砍掉了什么

  • 年带、月头三条轨道、31 格密度条、数据带、档案层、年份导航；
  • 年 / 月标题，以及它们身上的文件数和事件数；
  • 「查看详情」按钮。

数据是合成的；卡片里的日期、张数、公里数都自洽。
